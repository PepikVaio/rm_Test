### Anwendung
* < <<RM0>>> - Lesen Sie ohne störende Elemente und folgen Sie Ihren Statistiken.
* < <<RM0>>> - Unbegrenzte Optionen, um in PDF-Dateien zurück zu springen.
* < <<RM0>>> - Werkzeugleiste anpassen (Taste zum Öffnen der Symbolleiste und Schaltfläche zum Schließen des Dokuments).

* < <<RM0>>> - Ehrfürchtige Uhr in der reMarkable Sidebar (Sie können Feiertage, besondere Tage und Wetter hinzufügen).
* < <<RM0>>>> - Teilweise Übersetzung des Seitenteils ins Tschechische. Eine verbesserte Version wird in Kürze verfügbar sein.

* <<RM0>>> - Enchante dein ReMarkable mit einer gemütlichen guten Nachtnote für einen leichten Schlafmodus.
* < <<RM0>>> - Ein bisschen Magie und Ihr ReMarkable auf Sie wird Tschechisch sprechen.

* < <<RM0>>> - Erweiterung der Werkzeugauswahl beim Schreiben.
