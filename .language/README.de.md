# Xovi Erweiterung!
> Passen Sie Ihre reMarkable Tablette mit diesen Erweiterungen an.
> <br>
> Diese Erweiterungen bringen mehr Freiheit für Ihre reMarkable Tablette.
- getestet - reMarkable 2
- getestet - reMarkable Paper Pro

<br>

## Installation
Dateien `.qmd`, `.rcc` und `.json` (falls verfügbar) Kopie an `/home/root/xovi/exthome/qt-resource-rebuilder`.

> [!IMPORTANT]
> Stellen Sie vor der Installation sicher, dass Sie alle Anforderungen erfüllen:
> - reMarkable 1/2, reMarkable Paper Pro
> - [Xovi](https://github.com/asivery/rm-xovi-extensions/tree/master)

> [!TIP]
> Ich empfehle die Installation dieses Erweiterungstyps für eine bessere Konfiguration anderer Erweiterungen:
> - [xovi_Settings_Main](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/xovi_Settings_Main)


### Anwendung
* [document_Reader_Mode](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/document_Reader_Mode) - Lesen ohne störende Elemente und folgen Sie Ihren Statistiken.
* [document_Multiple_Navigation_History](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/document_Multiple_Navigation_History) - Unbegrenzte Sprungoptionen zurück in PDF-Dateien.
* [document_Toolbar_X](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/document_Toolbar_X) - Werkzeugleiste anpassen (Taste zum Öffnen der Symbolleiste und Schaltfläche zum Schließen des Dokuments).

* [sidebar_Clock](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/sidebar_Clock) - Ehrfürchtige Uhr in der Seitenleiste reMarkierbar (Sie können Feiertage, besondere Tage und Wetter hinzufügen).
* [sidebar_Translated](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/sidebar_Translated) - Teilweise Übersetzung der Seitenwand ins Tschechische. Eine verbesserte Version wird in Kürze verfügbar sein.

* [system_Light_Sleep](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/system_Light_Sleep) - Charming Ihr reMarkable mit einer gemütlichen guten Nachtnote für einen leichten Schlaf-Modus.
* [system_Translation](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/system_Translation) - Ein kleiner Zauberspruch und Ihr ReMarkable auf Sie wird Tschechisch sprechen.

* [toolbar_Expand_Typing](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/toolbar_Expand_Typing) - Erweiterung der Werkzeugauswahl beim Schreiben.

* [xovi_Settings_Example](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/xovi_Settings_Example) - Beispiel für eine benutzerdefinierte Einstellung zur Erweiterung von `xovi_Settings_Main`.
* [xovi_Settings_Main](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/xovi_Settings_Main) - Hinzufügen von Einstellungen zu Ihrer Erweiterung.
