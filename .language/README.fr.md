# Xovi rozsireni !
> Ajustez votre comprimé reMarkable avec ces extensions.
> < b >
> Ces extensions offrent une plus grande liberté à votre tablette reMarkable.
- Testé - reMarkable 2
- Testé - reMarkable Paper Pro

<br>

## Installation
`.qmd`, `.rcc` et `.json` (s'ils sont disponibles) sont copiés sur `/home/root/xovi/exthome/qt-resource-rebuilder`.

> [!IMPORTANT]
> Avant d'être installé, assurez-vous de satisfaire à toutes les exigences:
> - reMarkable 1/2, reMarkable Paper Pro
> - [Xovi] (https://github.com/asivery/rm-xovi-extensions/tree/master)

> [!TIP]
> Je recommande d'installer ce type d'extension pour une meilleure configuration des autres extensions.:
> - [xovi_Settings_Main] (https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/xovi_Settings_Main)


### Utilisation
* [document_Reader_Mode] (https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/document_Reader_Mode) - Lisez sans éléments perturbateurs et suivez vos statistiques.
* [document_Multiple_Navigation_Histoire] (https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/document_Multiple_Navigation_History) - Options de saut illimitées dans les fichiers PDF.
* [document_Toolbar_X] (https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/document_Toolbar_X) - Adaptation de la barre d'outils (le bouton pour ouvrir la barre d'outils et fermer le document).

* [sidebar_Clock] (https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/sidebar_Clock) - Horloge fantastique dans le panneau de bord reMarkable (vous pouvez ajouter des jours fériés, des jours spéciaux et le temps).
* [sidebar_Translated] (https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/sidebar_Translated) - Traduction partielle de la barre latérale en tchèque. Une version améliorée sera bientôt disponible.

* [system_Light_Sleep] (https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/system_Light_Sleep) - Charmez votre reMarkable avec un message confortable pour une bonne nuit de sommeil léger.
* [system_Translation] (https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/system_Translation) - Un peu de magie et votre reMarkable vous parlera en tchèque.

* [toolbar_Expand_Typing] (https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/toolbar_Expand_Typing) - Augmenter la sélection des outils lors de l'écriture.

* [xovi_Settings_Example] [https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/xovi_Settings_Example) - Exemple de réglage personnalisé pour l'extension de `xovi_Settings_Main`.
* [xovi_Settings_Main] (https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/xovi_Settings_Main) - Ajoutez les paramètres à votre extension.
