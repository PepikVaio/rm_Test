# Extension Xovi !
> Personnalisez votre tablette reMarkable avec ces extensions.
> <br>
> Ces extensions apportent une plus grande liberté à votre tablette reMarkable.
- Testé - reMarkable 2
- Testé - reMarkable Paper Pro

<br>

## Installation
Copier les fichiers `.qmd`, `.rcc` et `.json` (si disponible) vers `/home/root/xovi/exthome/qt-resource-rebuilder`.

> [!IMPORTANT]
> Avant l'installation, assurez-vous de répondre à toutes les exigences :
> - reMarkable 1/2, reMarkable Paper Pro
> - [Xovi](https://github.com/asivery/rm-xovi-extensions/tree/master)

> [!TIP]
> Je recommande d'installer ce type d'extension pour une meilleure configuration d'autres extensions.:
* - [xovi_Settings_Main](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/xovi_Settings_Main)


### Demande
* [document_Reader_Mode](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/document_Reader_Mode) - Lisez sans interférer avec les éléments et suivez vos statistiques.
* [document_Multiple_Navigation_History](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/document_Multiple_Navigation_History) - Options de saut illimités dans les fichiers PDF.
* [document_Toolbar_X](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/document_Toolbar_X) - Personnaliser la barre d'outils (bouton pour ouvrir la barre d'outils et bouton pour fermer le document).

* [sidebar_Clock](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/sidebar_Clock) - Horloge incroyable en sidebar reMarkable (vous pouvez ajouter des vacances, des jours spéciaux et la météo).
* [sidebar_Translated](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/sidebar_Translated) - Traduction partielle du panneau latéral en tchèque. Une version améliorée sera bientôt disponible.

* [system_Light_Sleep](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/system_Light_Sleep) - Charmant votre reMarkable avec une bonne note de nuit confortable pour un mode de sommeil léger.
* [system_Translation](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/system_Translation) - Un petit sort et votre reMarkable sur vous parleront tchèque.

* [toolbar_Expand_Typing](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/toolbar_Expand_Typing) - Élargir la sélection d'outils lors de l'écriture.

* [xovi_Settings_Example](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/xovi_Settings_Example) - Exemple de paramètres personnalisés pour l'extension `xovi_Settings_Main`.
* [xovi_Settings_Main](https://github.com/PepikVaio/reMarkable_Xovi_Extensions/tree/main/xovi_Settings_Main) - Ajouter des paramètres à votre extension.
